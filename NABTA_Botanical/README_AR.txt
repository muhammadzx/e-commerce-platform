الأقسام الرئيسية بارتفاع مساحة الشاشة على الكمبيوتر. على الهاتف/الشاشات القصيرة أو مع تكبير النص يسمح بالتمرير الضروري حتى لا ينقطع المحتوى. نموذج البيع مقسم إلى معلومات أساسية ثم نافذة الصور والوصف.
النوافذ الأصلية تحتاج متصفحًا حديثًا وتغلق بزر Escape أو الإغلاق.

المنتجات والأسعار والمراجعات والإحصائيات أمثلة. صور العبوات والمستلزمات المولدة تصاميم توضيحية. بيانات علاجات النباتات لا تتضمن مادة فعالة أو جرعة أو ادعاء فعالية. تُستبدل ببيانات الملصق الفعلية عند إضافة منتجات حقيقية.

SEO: عنوان ووصف لكل صفحة، H1 واحد، عناصر دلالية، نصوص بديلة، تحميل كسول للصور غير الرئيسية، noindex للحساب والإدارة. تُضاف canonical وsitemap بعد تحديد الدومين. noindex ليس نظام صلاحيات.

المراجعة: فحص الروابط والملفات ومعرفات الحقول والنوافذ في جميع الصفحات. معاينة المتجر بالكمبيوتر وبعرض 390 بكسل، تجربة انتقال السلايدر ونافذة الصور والوصف. هذه ليست شهادة توافق شاملة لكل الأجهزة أو معايير الوصول.

تحديث الحديقة المفتوحة: افتتاحية بصورة تغطي الشاشة، درجات خضراء وزرقاء مستوحاة من الطبيعة. انتقالات CSS هادئة بين العروض عبر الأرقام، مع احترام prefers-reduced-motion. جميع الصفحات والواجهات السابقة محفوظة.
